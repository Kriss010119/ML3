# Запуск

Нужен Python 3.12 или новее. Главное – чтобы версия scikit-learn совпадала с той, в которой 
сохранена модель, иначе joblib.load может выдать ошибку (как было у меня)

```
cd wine_app
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на http://localhost:8501.

# Кэширование 

- Модель: @st.cache_resource - это один объект, разделяется между сессиями и перезапусками скрипта без копирования 
- @st.cache_data - результат сериализуется, и при каждом вызове функция возвращает новую копию. Для таблиц это безопасно потому что изменение DataFrame в одном месте не портит кэш + для модели копирование на каждый вызов было бы лишним
- Вероятности на тесте от порога не зависят, поэтому считаются один раз
- При движении слайдера пересчитывается только сравнение proba >= threshold
- Если вызвать joblib.load без декоратора, модель будет читаться с диска и десериализоваться при каждом действии пользователя, а в памяти будет отдельная копия на каждую сессию и как итог итерфейс станет заметно медленнее
